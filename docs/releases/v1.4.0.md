# 薪动 v1.4.0 · macOS 菜单栏版

## 下载与安装

本次发布面向 **Apple Silicon / ARM64，macOS 27.0 及以上**。实测为 macOS 27.0.1 / Apple M5。

- `SalaryMotivator-1.4.0-macos-arm64.dmg`：推荐。打开后把“薪动”拖入 Applications。
- `SalaryMotivator-1.4.0-macos-arm64.zip`：解压即得自带运行环境的 `薪动.app`。
- `xindong-macos-1.4.0-source.zip`：对应本次发布的源码，不包含个人配置。
- `SHA256SUMS.txt`：下载文件 SHA-256 校验值。
- `BUILD-INFO.json`：源码提交、平台及构建信息。

应用为本地临时签名，未经过 Apple Developer ID 签名或公证。macOS 如提示无法验证开发者，请先核对来源与校验值，再参考 [Apple 官方说明](https://support.apple.com/en-gb/102445)。

## 功能

- 默认仅在菜单栏后台运行，不占 Dock；单击金额展开面板，右键设置/退出。
- 实时收入保留四位小数，状态栏与面板显示下班倒计时。
- 1280 项、32 类趣味参考物品，单项价格 ¥2.00–¥9498.10；攒够自动随机换下一件。
- 物品仅在展开时显示。从启用时开始攒钱，夜间/休息日暂停，重启恢复进度。
- 中国节假日与调休通过 HTTPS 自动更新，断网使用内置数据与缓存，手动日期优先。
- 保留八套配色、工资与工作时间设置、透明度和登录启动。

物品价格是预设参考估值，不是商家实时报价，不会发生真实购买。计薪秒数不包含夜间与休息日等待时间。
